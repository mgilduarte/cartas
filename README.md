# 🍷 Cartas - Bar La Ponderosa

Repositorio dedicado a la gestión y despliegue de las cartas digitales del **Bar La Ponderosa**.

---

## ❄️ Carta de Invierno

Esta sección contiene la versión adaptada exclusivamente para la **temporada de invierno**, enfocada en una experiencia completa de vinos sin servicio de cocina.

### 📋 Características
- **Menú Exclusivo de Vinos:** Filtrado por categoría (Vinos Tintos y Vinos Blancos).
- **Diseño Responsive:** Adaptado para una visualización fluida desde teléfonos móviles (Mobile-First).
- **Visualización de Productos:** Fotografías individuales de cada botella, precios por copa/botella e información detallada.
- **Información del Local:** Horarios de invierno y enlaces a redes sociales.
